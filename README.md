# PushBird · 0.02

用身体动作控制小鸟的摄像头互动游戏。小鸟跟随鼻尖，独立的额头识别让黄色 SCORE 牌悬在头部上方；也可以使用键盘、鼠标和触摸游玩。

发布标签为 `0.02`；npm 清单使用对应的语义版本号 `0.0.2`。挑战分数表示通过水管数，引导模式表示已播放的完整计时周期；两者都不是经过验证的俯卧撑次数或动作质量评分。

## 0.02 三段节奏引导

首页选择“引导训练”，默认 `2-1-2`：慢下2秒、底停1秒、推起2秒。展开“训练节奏”可以选择 `3-1-1` 或自定义；慢下/推起可设0.5–6秒，底停可设0–3秒，步长0.5秒。它们是可调产品预设，不是人人适用的训练处方。

三段进度条按各段实际秒数分配宽度，同时显示阶段、剩余时间和呼吸提示。绿色虚线是节奏示意轨迹，不是动作幅度测量；鼻尖仍控制小鸟，目标光点仅演示阶段变化。没有碰管死亡，可随时暂停、重新练习或结束。恢复前有准备倒计时，并从本周期的慢下重新开始；“重新练习”清空本轮周期数，保留历史纪录。

音乐开关同时控制音效与可选阶段语音。设备支持时可勾选语音提示，发声时背景音乐减弱；语音是否可用及是否联网由浏览器/设备语音服务决定，缺失时仍保留文字和音效。

切后台、打开说明、已建立的头部跟踪丢失或画面长时间卡顿都会暂停引导，恢复后不自动补计或追放提示。无摄像头/识别不可用时可作为计时引导使用；它不检测用户是否实际做动作。周期纪录按所选节奏分别保存，与原版挑战纪录完全独立。

## 触摸、鼠标与键盘调速

右上角速度数字可拖动：**向左拨加速、向右拨减速**，每横移约32 CSS px改变10%，范围50%–200%。触摸、触控笔与鼠标共用Pointer Events；竖向拖动和轻微抖动不调速，手指离开数字区域后仍可继续同一次拖动。只有速度数字区域拦截拖动，不影响画布触摸控制。

点击数字显示44px及以上触摸按钮，可加速、减速或恢复默认；键盘聚焦数字后左/上加速、右/下减速，Home恢复100%，Escape收起。挑战模式显示实际水管px/s，并同时调整已出现与新生成的水管速度；引导模式显示播放倍率，保留当前阶段进度并按倍率换算剩余真实秒数。两种模式的速度各自保留到本次页面关闭，重新加载恢复100%。引导周期纪录只按节奏预设区分，没有承诺不同倍率之间的训练成绩可比。

## 功能

- 鼻尖直接控制小鸟横纵位置，无重力下坠；补偿摄像头镜像与画面裁剪。
- SCORE 牌独立跟随额头中央，牌子中心在额头上方 200 CSS px；空间不足时限制在屏幕内侧 8px。
- 前 3 道水管免死练习，第 4 道起碰到水管立即 Game Over；干净通过才加分。
- 首页“开始挑战”保留以上原版规则；“引导训练”提供独立三段计时，不做碰撞判罚。
- 水管缺口按保持、下压、撑起交替；上方对称显示标题与实际水管速度。
- 0.02水管密度提高30%，同等速度下生成间隔由3–2.4秒调整为约2.31–1.85秒；前三道保护仍在。
- 轻快本地循环背景音乐，按钮同时控制音乐与音效；结束、页面隐藏或离开时暂停。
- 首次得分有鼓励；打破本浏览器个人纪录时闪红并撒七彩纸屑，追平不误报，同局不重复弹出。
- 个人最高分保存在本地浏览器；减少动态模式使用静态提示，省略飘落纸屑。
- HOW IT WORKS 说明抽屉支持点击外部、X 或 Escape 收起。
- 摄像头被拒绝、识别失败或丢失时保留手动控制，离页释放资源。

## 快速运行

需要 Node.js 20 或更高版本，建议 Node.js 22 LTS。

```bash
npm ci
npm run dev
```

在浏览器打开 `http://127.0.0.1:3000/`，选择“引导训练”或“开始挑战”，按需允许摄像头。摄像头需要 localhost 或 HTTPS 的安全上下文。

`npm run dev` 会自动下载固定版本的官方人脸模型、核对 SHA256，并从本地依赖准备 WASM 和 Worker。下载只在模型缺失时发生；已有模型哈希不匹配会报错并保留原文件。模型文件和生成的运行时不纳入 Git。

3000 端口被占用时可运行：

```bash
npm run dev -- --port 14560
```

开发/预览服务器默认只监听回环地址，不会自动开放局域网。

## 控制

| 模式 | 操作 |
| --- | --- |
| 摄像头 | 鼻尖移动控制小鸟；额头识别独立定位 SCORE |
| 键盘 | ↑ / Space 上移，↓ 下移；Space 可开始新局 |
| 鼠标/触摸 | 点击画面不同高度控制小鸟 |
| 说明抽屉 | HOW IT WORKS 打开，点外部、X 或 Escape 关闭 |
| 音乐 | ♫ 切换背景音乐与音效 |
| 调速 | 左拨速度数字加速、右拨减速；点击数字可用加减/默认按钮 |

## 验证与构建

Windows 默认使用标准安装路径的 Google Chrome；其他平台安装 Playwright Chromium：

```bash
npx playwright install chromium
npm run check
```

可用环境变量 `PUSHBIRD_CHROME` 指定其他 Chromium 可执行文件；`PUSHBIRD_TEST_ARTIFACTS` 可指定本地测试截图目录。请把截图输出放在仓库之外。

```bash
npm test          # Node 测试运行器 + 独立无头浏览器
npm run build     # 模型/运行时准备 + Vite 静态构建
npm run preview   # 预览 dist，默认 127.0.0.1:3000
```

`npm run check` 覆盖计时边界、训练交互与原版挑战回归。摄像头、Pose、人脸 Worker 和可选语音边界使用受控替身；0.01另已用官方示例人像运行真实人脸模型。浏览器回归不能代替真人摄像头、真实俯卧撑、实际语音服务与 iPad/Safari 验收。

## 网络与数据

摄像头图像在当前浏览器内处理，应用没有视频上传接口。人脸推理使用本地模型和 WASM；鼻尖追踪首次启用时仍从 jsDelivr 加载 MediaPipe Pose，像素字体从 Google Fonts 加载，因此目前不是完整离线应用。

个人纪录使用当前站点的 `localStorage`：挑战为 `pushbird.bestScore`，引导为 `pushbird.tempoBest.<下降>-<底停>-<推起>`。换浏览器、换端口或清除站点数据会有独立纪录；存储不可用时游戏仍能运行，但不能保证刷新后保存。

| `src/main.js` | 游戏循环、计分、输入、UI、音频与资源生命周期 |

| `scripts/setup-models.mjs` | 下载并校验固定版本官方模型 |
