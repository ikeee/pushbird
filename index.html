PUSHBIRD / 01
BUILD NOTES / 01

从视频到应用

把身体动作，
翻译成游戏引擎。

这个版本把视频中的“实景 + 像素游戏”拆成四层：摄像头、姿态信号、Canvas 游戏循环和 UI 状态。

01

摄像头接入

getUserMedia() 请求前置摄像头。视频只做背景，不参与游戏绘制；浏览器拒绝权限时，游戏自动保留键盘/触摸模式。

02

头部跟随

MediaPipe Pose 读取鼻子这个头部关键点。把摄像头中的垂直坐标平滑映射到游戏画布，小鸟会实时跟随你的头部上下移动，而不是自动下坠。

03

训练反馈

俯卧撑下压时头部下降，小鸟同步下降；撑起时头部上升，小鸟同步上升。绿色管道缺口是你的动作目标，连续穿越就是稳定节奏。

04

练习与反馈

缺口按下压与撑起交替。前 3 道水管有保护，第 4 道起碰撞立即 Game Over；干净通过才加分。界面显示当前水管速度，音乐按钮可同时开关背景音乐与音效。分数是通过缺口数，不是俯卧撑次数。

TIP

首次体验请允许摄像头，把头部保持在画面内；没有摄像头时，点击画面不同高度可模拟头部位置。
